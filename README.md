# VYOJIN Homepage — Task Layout Build

## Structure

- `index.php` — homepage entry point; uses the original task layout and includes reusable header/footer.
- `header.php` — task header/announcement markup.
- `footer.php` — task footer markup.
- `css/site.css` — consolidated task stylesheet with the Vyojin visual skin.
- `css/hero-slider.css` — isolated hero slider styles.
- `js/site.js` — local core interaction scripts used by the layout.
- `js/slider.js` — dedicated hero slider logic.
- `assets/hero/hero-1.jpeg`, `hero-2.jpeg`, `hero-3.jpeg` — local hero slides.
- `assets/logo/` — Vyojin logo.
- `assets/vyojin/` and `assets/sections/` — local Vyojin photography.
- `assets/fonts/` — local fonts.
- `assets/ui/` — local UI icons.

## Important

- No geo-location redirect or redirect notification is included.
- No external analytics/tracking scripts are loaded.
- No ImageKit product-image requests are loaded.
- No Kalki branding is included.
- The original task homepage/layout structure is preserved; the Vyojin skin/assets are applied on top.
